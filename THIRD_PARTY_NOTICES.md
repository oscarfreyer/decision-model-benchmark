# Third-party material

The code is released under MIT; the structured study results and figures are released under CC BY 4.0. Dependencies retain their own licences and are installed separately.

MedQA is obtained from its upstream repository, https://github.com/jind11/MedQA. The recorded upstream licence is MIT, copyright 2022 Di Jin. This repository does not include upstream question stems, option text or a separate reference-key file. The released selected labels and correctness can reveal reference answers; the MedQA answer keys are publicly available upstream. Obtain those files directly from upstream and retain its licence notice when keeping or redistributing copies.

Publication figures use Arial. The font binary is not distributed. Obtain Arial lawfully and use the font file identified by the presentation provenance for an exact rendering match. A different font requires an explicit figure-setting change and creates a different presentation.

The collection code uses hosted model APIs. Model weights are not distributed. API/provider terms and availability govern any new collection. The public data contain structured study measurements rather than raw request/response bodies or reasoning text.
